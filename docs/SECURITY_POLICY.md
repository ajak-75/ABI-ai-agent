# 보안 정책 — PHASE 1

## 원칙

1. **기본은 로컬.** 대화·기억·작업 기록은 기기 안 SQLite에만 있습니다. 서버·클라우드 동기화가 없습니다.
2. **비밀은 코드에 없다.** API 키는 소스·SQLite·로그 어디에도 남기지 않고 `expo-secure-store`(Android Keystore)에만 둡니다.
3. **바깥으로 나가는 일은 사람이 정한다.** 돈·계정·다른 사람에게 영향을 주는 작업은 승인 없이는 실행하지 않습니다.
4. **한 일은 남는다.** 앱이 실제로 한 동작은 감사 로그에 append-only로 기록됩니다.

## 1단계의 네트워크 상태

- HTTP 클라이언트 라이브러리가 설치되어 있지 않고, 앱 코드에 외부 요청이 없습니다.
- Metro 개발 서버(로컬 PC)와의 통신은 개발 빌드 특성이며 앱 기능과 무관합니다.
- `expo-dev-client`는 개발용 런처로, 배포용(프로덕션) 빌드에서는 제외하는 것을 권장합니다.

## 비밀 관리 (`src/security/secrets.ts`)

| 항목 | 처리 |
| --- | --- |
| 저장 위치 | `SecureStore` (Android Keystore, `WHEN_UNLOCKED`) |
| 저장 키 | `ajak.aiagent.apikey.<provider>` (prefix + provider) |
| 화면 표시 | 마지막 4자리만 `•••• xxxx` 형태로 |
| 로그 | 값 자체를 절대 남기지 않음(`settings.api_key_saved`에는 provider만) |
| 삭제 | 설정 화면에서 명시 삭제, 확인 다이얼로그 필수 |
| 폴백 | 보안 저장소를 쓸 수 없는 기기에서는 저장을 거부하고 안내(평문 저장 대체 없음) |

## 승인 정책 (`src/security/approvals.ts`)

| 위험도 | 예시 | 정책 |
| --- | --- | --- |
| 낮음(low) | 기기 안 읽기, 되돌릴 수 있는 조회 | 승인 없이 가능 |
| 보통(medium) | 앱 밖 데이터 변경, 알림·일정 생성 | **사용자 승인 필요** |
| 높음(high) | 결제, 계정 변경, 외부로 전송 | **사용자 승인 필요** |

금지 범주(항상 거부): `payment_without_confirmation`, `credential_export`.

1단계에서는 승인 대기 목록에 실제 도구 요청이 생기지 않습니다(레지스트리 비어 있음). 승인 흐름 검증용 '테스트 요청'은 `demo.notification`이라는 가짜 도구 id를 쓰며, 승인해도 아무 것도 실행되지 않는다고 화면에 명시합니다.

## 감사 로그

- 테이블: `audit_logs` (id, task_id, action, detail, created_at)
- 기록 시점: 앱 시작, 메시지 저장, 라우팅 결정·응답, 기억 생성/삭제, 세션 삭제, 작업 생성, 승인/거절, 설정 변경, 데이터 삭제
- 값 노출 금지: API 키 원문, 메시지 전문(길이·앞부분만)
- 로그 기록 실패는 사용자 동작을 막지 않습니다.

## 데이터 삭제 권한

| 동작 | 결과 | 확인 |
| --- | --- | --- |
| 대화 기록 전체 삭제 | messages·sessions·memories·tasks·audit_logs 삭제 | 다이얼로그 |
| 데이터베이스 초기화 | DB 파일 삭제 후 재생성 | 다이얼로그 |
| 세션 삭제 | 해당 세션 메시지 CASCADE 삭제 | 다이얼로그(메시지 수 표시) |
| 기억 삭제 | 해당 행 삭제 | 다이얼로그(내용 표시) |
| API 키 삭제 | Keystore 항목만 삭제 | 다이얼로그 |

## 앱 권한

1단계 매니페스트(`expo prebuild` 결과)에 선언된 권한과 출처:

| 권한 | 출처 | 앱 코드 사용 |
| --- | --- | --- |
| `INTERNET` | React Native/Expo 기본 | 1단계 앱 코드에 네트워크 요청 없음(개발 서버·업데이트 매니페스트용) |
| `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE` | Expo 템플릿 기본 (`maxSdkVersion=32`) | 사용하지 않음(Android 13+ 에서는 요청되지 않음) |
| `SYSTEM_ALERT_WINDOW` | `expo-dev-client`(개발 빌드 오버레이) | 개발 메뉴용. 프로덕션 빌드에서는 제거 검토 |
| `VIBRATE` | React Native 기본 | 사용하지 않음 |

카메라·위치·연락처·마이크·SMS 권한은 **선언하지 않았습니다.** 3단계에서 도구를 붙일 때 필요한 권한만, 사용 목적 문구와 함께 추가합니다.

## 로그·디버그

- `console.log`로 비밀·메시지 전문을 출력하지 않습니다.
- 개발 빌드에서도 화면에는 키 원문이 나타나지 않습니다(입력 필드는 `secureTextEntry`, 저장 후 즉시 비움).

## 남은 결정 사항

- 3단계: APK 서명 키 보관 방식(EAS 관리형 vs 자체 보관) — 배포 전 결정 필요
- 4단계: 로컬 백업 파일 암호화 여부
- 프로덕션 빌드에서 `expo-dev-client` 제거 및 디버그 로그 정리

# 프로젝트 개요 — Android AI Agent

## 한 줄 정의

내 Android 폰 안에서 대화·기억·승인 기록을 스스로 보관하는 **로컬 우선 개인 AI 에이전트 앱**입니다.

## 왜 별도 프로젝트인가

- 기존 작업(`work/diary`, `work/KOMI-Diary`, `work/ajak-studio`, `danjjan-smartstore-prep`)은 손대지 않습니다. 이 앱은 별도 저장소·별도 패키지(`com.ajak75.androidaiagent`)·별도 DB 파일(`ajak-ai-agent.db`)을 씁니다.
- Pickle 내부 구조나 비공개 규칙을 참조하지 않고, **공개 오픈소스(Expo, React Native, TypeScript, expo-sqlite, expo-secure-store)** 만으로 구성했습니다.

## 1단계 목표 (이번 범위)

1. 신규 프로젝트 + GitHub 신규 저장소 백업
2. Android 기본 앱 화면 4개(대화·기억·작업·설정) + 채팅 인터페이스
3. SQLite 대화 기록 저장·조회 — **앱을 완전히 종료했다 다시 열어도 유지**
4. 기본 설정 화면(경로 선택·API 키 보관·데이터 관리)
5. Android 테스트 APK 빌드 가능 여부 확인
6. 초기 예산 0원

## 1단계에서 명시적으로 제외한 것

| 제외 항목 | 이유 | 들어갈 단계 |
| --- | --- | --- |
| 로컬 LLM 추론(libllama 등) | 기기 성능·바이너리 크기 검증이 먼저 필요 | 2단계 |
| 외부 API 호출(HTTP 클라이언트) | 키·요금·정책 확정 전에는 코드 자체를 넣지 않음 | 2~3단계 |
| 실제 도구 실행(알림·캘린더·연락처) | 승인 흐름을 먼저 완성 | 3단계 |
| 계정·동기화·서버 | 로컬 전용이 1단계 원칙 | 4단계 이후 검토 |

따라서 지금 채팅에 오는 답변은 **모델 출력이 아니라** `PHASE 1 · 테스트 응답` 배지가 붙은 안내문입니다. 화면·저장·라우팅이 실제로 동작하는지 확인하는 용도입니다.

## 사용자가 체감하는 결과

- 메시지를 보내면 즉시 말풍선이 쌓이고, 앱을 죽였다 켜도 그대로 있습니다.
- 대화 세션을 여러 개 만들고, 기억 탭에서 세션을 골라 다시 열 수 있습니다.
- 기억 탭에 "나는 짧은 답을 좋아한다" 같은 선호를 적어 두면 로컬 DB에 남습니다.
- 작업 탭에서 승인 대기/기록을 보고, 승인·거절 결정이 감사 로그로 남는 것을 확인할 수 있습니다.
- 설정에서 경로(로컬/무료 클라우드/자동)를 고르고, API 키를 Keystore에 보관(마스킹 표시)할 수 있습니다.

## 성공 기준

| 기준 | 확인 방법 |
| --- | --- |
| 타입 오류 0 | `npm run typecheck` |
| Expo 설정 유효 | `npm run config`, `npm run doctor` |
| 대화 영속성 | 메시지 전송 → 앱 강제 종료 → 재실행 → 동일 세션·메시지 표시 |
| 비밀 비노출 | 설정 화면에서 `•••• xxxx` 힌트만 표시, 코드에 키 문자열 없음 |
| 0원 | EAS 무료 티어 또는 로컬 빌드만 사용, 유료 구독 없음 |
